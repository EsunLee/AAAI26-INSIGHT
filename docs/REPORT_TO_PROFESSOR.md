## 一、项目目标

复现 INSIGHT 两阶段长时动作预测框架：

- **Stage 1**（手物语义动作识别）：提取手物交互（HOI）特征，结合 verb-noun 共现矩阵做语义修正，识别当前动作
- **Stage 2**（显式认知推理）：Qwen2.5-VL-7B + 强化学习，按 think → intention → answer 结构推理，预测未来 20 个动作

## 三、核心结果

### 3.1 格式层面：SFT 完全成功 ✅

| 指标 | GRPO (1,773步) | SFT (200步) |
|------|:--:|:--:|
| 20 动作格式正确率 | ~5.8% | **91.6%** |
| `<answer>` 标签率 | ~99% | **100%** |
| 精确 20 动作率 | 91.6% | **92.0%** |

### 3.2 语义层面：尚未突破 ❌

| 指标 | 数值 | 说明 |
|------|:--:|------|
| Stage 1 Action Top-1 | 3.56% | 诊断性指标（非官方协议） |
| Stage 1 Action Top-5 | 11.16% | 同上 |
| Stage 2 下一动作 Top-1 | 0.80% | 876 条命中 7 条 |
| Stage 2 Hit@5 | 1.60% | 5 候选命中 14 条 |
| Stage 2 Action 编辑距离 | 0.982 | 1.0 = 完全随机 |

### 3.3 一句话结论

> **两阶段全链路已完整复现并跑通**（数据 → 特征 → Stage1 → Stage2 → 评测）；模型学会了输出格式，但尚未学会动作语义。瓶颈已精确定位，见下节。

### 3.4 Stage 2 的两次训练尝试（GRPO → SFT）

Stage 2 的输入是"8 个历史动作文本（Stage 1 预测）+ 当前帧图像"，输出 20 个未来动作（think → intention → answer 三段式）。我们先后尝试了两种训练方式：

| 方式 | 机制 | 结果 |
|------|------|------|
| **GRPO**（论文原方案） | 不给答案：同一输入采样 N 个候选，奖励函数打分，按组内优劣更新。能优化不可微的语义奖励 | 1,773 步，内容奖励恒 ≈ 0（老师不批改，学生学不动），仅学会格式皮毛（5.8%）❌ |
| **SFT**（我们的修复） | 给标准答案：交叉熵逐 token 模仿标注答案。简单、快、稳定 | 200 步格式 91.6% ✅，但语义 Top-1 仍 0.8% ❌ |

- **为什么是两个过程**：论文只做 GRPO；我们因奖励全零失败后补 SFT 先锁格式，这正好符合 RLHF"先 SFT 后 RL"的标准顺序——跳过 SFT 直接 RL，模型连格式都不会，奖励信号必然稀疏。
- **为什么语义仍没学会**：Stage 1 Top-1 仅 3.56%，8 个历史动作几乎全错 → Stage 2 无论背答案（SFT）还是考试（GRPO），读到的都是错题 → 只能学"怎么答"，学不会"答什么"。**Stage 1 是出题人，Stage 2 是考生；出题人给错题，考生怎么练都考不了高分。**

### 3.5 官方协议 mAP baseline（EGO-TOPO）✅

在 EGO-TOPO 官方划分与评测协议下，用现有特征跑出长期未来动词 mAP：

| 组别 | 我们（feature-limited） | 论文 INSIGHT |
|------|-----------------------:|------------:|
| All | **46.2** | 45.2 |
| Freq | **53.8** | 62.4 |
| Rare | **41.1** | 36.0 |

> **诚实边界**：验证集仅 96 个阶段样本（官方协议过滤 + 特征缺失，覆盖率 ~56%）、评估类别 64 类、特征为 1024-dim CLIP 而非论文 EgoVideo-V 1408-dim。All 反超论文 1.0 分属小样本噪声，不可解读为超越；**Freq 落后 8.6 分**与 HOI 特征缺失的诊断一致（高频动作恰是手物交互密集类）。该数字证明协议管线已就绪，论文级对比需真实特征。

## 四、瓶颈定位（根因分析）

通过逐文件审计（SHA256 + 逐字节比对），瓶颈被精确定位为**外部预训练权重缺失**，而非方法设计问题：

### 根因 1：HOI 特征缺失（最主要）

```text
论文使用: handobj_100K + ego 权重（第一人称手检测器，作者未开源）
我们使用: handobj_100K（仅第三人称训练）

→ EK55 胸戴相机画面手部检出率仅 0.6% (91/15,480)
→ 检不到手 → 没有手物交互区域 → mask 特征无法生成
→ 临时方案：mask 特征 = frame 特征副本
→ 双流模型实质退化为单流（审计确认：98% 特征逐字节相同）
```

**后果**：论文核心创新点"HOI 增强"未生效，Stage 1 只能依赖整帧画面判断动作，识别率被锁死在 3.56%。

### 根因 2：EgoVideo-V 权重缺失

```text
论文使用: EgoVideo-V (1408 维，视频级时序建模)
我们可用: EgoVideo 官方仓库中的 1024 维 CLIP ViT-L/14（图像级）

→ 特征容量低 27%
→ 丢失时序动态信息（逐帧编码后平均，无视频级建模）
```

**后果**：输入特征的信息量低于论文，Stage 1 无法达到论文识别能力。

### 根因 3：错误传导放大

```text
Stage 1 Top-1 3.56% → 8 个历史动作中期望正确数仅 0.28 个
→ Stage 2 输入的历史动作几乎全错
→ 模型无法从错误历史推断正确未来
→ 只能学格式（91.6%），学不到语义（0.8%）
```

### 因果链总图

```text
[作者未开源 handobj_100K+ego] ──→ HOI 检出率 0.6% ──→ 双流退化单流 ──┐
                                                                    ├─→ Stage 1 Top-1 3.56% ──→ Stage 2 语义失败 0.8%
[作者未开源 EgoVideo-V 1408维] ──→ 特征容量-27% + 无时序 ────────────┘
```
